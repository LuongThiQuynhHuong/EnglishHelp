# English Helper

English Helper is a vocabulary learning project. This repository has separate areas for its current application and future development.

## Project areas

- [MobileApp](MobileApp/README.md) contains the current mobile application and its setup, build, architecture, and development guide.
- [Network](Network/README.md) is reserved for future network-related development.
- [WebApp](WebApp/README.md) is reserved for future web application development.

See [AGENTS.md](AGENTS.md) for repository contribution rules. Each project area documents its own setup and implementation details.
